# Азаттық жолы — React/Vite/Supabase

## Локалды іске қосу
Node.js LTS орнатыңыз, жоба қалтасында `npm install`, содан кейін `npm run dev` орындаңыз.

## Supabase
1. https://supabase.com/ сайтында Free жоба жасаңыз.
2. `supabase/schema.sql` файлын SQL Editor ішіне көшіріп, Run басыңыз.
3. `.env.example` файлын `.env` деп көшіріп, `VITE_SUPABASE_URL` және `VITE_SUPABASE_ANON_KEY` мәндерін толтырыңыз.
4. Тек publishable/anon key қолданыңыз. `service_role` кілтін браузерге ешқашан жарияламаңыз.
5. Серверді қайта іске қосыңыз. Supabase бапталмаса, демо режимі тек сол браузерде сақтайды.

## Netlify арқылы тегін жариялау
1. Жобаны GitHub репозиторийіне жүктеңіз.
2. https://www.netlify.com/ → Add new site → Import an existing project → GitHub репозиторийін таңдаңыз.
3. Build command: `npm run build`; Publish directory: `dist`.
4. Site configuration → Environment variables ішіне екі `VITE_SUPABASE_...` айнымалысын қосыңыз.
5. Deploy жасаңыз. Netlify `*.netlify.app` сілтемесін береді. Айнымалыларды кейін қоссаңыз, қайта deploy қажет.

## Маңызды
- Сауалнамада 10 сұрақ, ашық/жабық/көп нұсқалы сұрақтар бар.
- 5 тапсырма автоматты түрде тексеріледі, ұпай мен қорытынды шығады.
- Нәтижелер бөлімі нақты жиналған жауаптарды талдайды. 100 респондентті жасанды түрде толтырмаңыз.
- Үш видео батырмасы қазір YouTube-тағы тақырыптық іздеуді ашады; нақты тексерілген видео URL-дерін `src/App.jsx` ішінен ауыстырыңыз.
- Тарихи даталар мен тұжырымдарды оқытушы ұсынған оқулықпен салыстырып, әдебиеттер тізімін толықтырыңыз.
